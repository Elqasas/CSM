Setting up the app registration
  1. In the Entra admin centre, App registrations → New registration. Single tenant, no redirect URI.
  2. API permissions → Microsoft Graph → Application permissions: Calendars.Read, User.Read.All, OnlineMeetings.Read.All, OnlineMeetingArtifact.Read.All. Then Grant admin consent.
  3. Certificates & secrets → new client secret. Copy its Value into the form above.
  4. For attendance, allow the app to read Teams meetings, in Teams PowerShell: 
    New-CsApplicationAccessPolicy -Identity Bousla -AppIds "<client id>"
Grant-CsApplicationAccessPolicy -PolicyName Bousla -Global
    Without it calendars still sync; attendance is never counted.
  5. Optional: limit which mailboxes the app may read with an Exchange application access policy (New-ApplicationAccessPolicy) scoped to a group holding the Bousla users.
