{% comment %} The layout a page uses when it is opened inside #form-modal rather than as a page of its own - see csm/core/modal.py. The page's own heading stays its title, so the dialog and the standalone page cannot word it differently; the breadcrumb is hidden, because inside a dialog you have not gone anywhere. The rules sit here rather than in app.css so they arrive with the markup they style: a browser holding yesterday's cached stylesheet would otherwise show a page-shaped form in a dialog-shaped box. A page's column was sized for a page; in a dialog it takes the full width. A bare card holding a form is flattened - the dialog is already the card - while a card with a header keeps its frame. {% endcomment %}
