{% comment %} The Bousla mark: a compass needle in a ring, drawn in the brand colour so it follows the theme. Inline rather than an because an image cannot read the page's custom properties, and the dark mode needs its own step. The size and fill attributes are the fallback for a page whose stylesheet has not loaded (or is a stale cached copy): without them an SVG fills its container in black. The stylesheet's rules outrank presentation attributes, so the theme still wins. {% endcomment %}
