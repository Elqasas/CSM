{% comment %} The repeat block: a switch, and the rule it reveals. Expects `form`. Hidden until the switch is on, with CSS rather than script - `:has()` is what every current browser uses for exactly this. If it were script, a slow CDN would leave the panel shut with no way to open it; as CSS the worst case is a panel that is always visible, and the fields are ignored anyway when the switch is off. A repeat is a rule and one live occurrence, never a hundred rows written up front: "Never" has no end to write up to, and a year of a daily task is three hundred entries nobody asked to see. Finishing one creates the next. {% endcomment %}
